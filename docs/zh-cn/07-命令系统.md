# 7. 命令系统

DolphinBot 有**两套并行的命令系统**——选哪个之前先理解它们的区别。

## 游戏内命令（`getCommands()`）

由聊天消息 `!` 或 `！`（中文感叹号）前缀触发。**玩家在游戏里输入**，只有 Bot 能看到。

```java
@Override
public void onEnable(RobotPlayer bot) {
    getCommands().register(
        new Command.Builder()
            .withName("uid")
            .allowedUsers("Melibertan")   // 可选白名单；省略 = 所有人可用
            .build((response, botInst) -> {
                String[] args = response.getCommandList();  // ["uid", "参数1", ...]
                String sender = response.getSender();       // 谁输入的
                botInst.getSession().sendChat("嗨，" + sender + "！");
            })
    );
}
```

## 终端命令（`getTerminalCommands()`）

由 Bot **控制台**输入 `/command` 触发（不是游戏内）。用于操作者级别的控制。Actions-Core 的 `/whereiam`、`/goto` 等命令走这套。

```java
@Override
public void onEnable(RobotPlayer bot) {
    getTerminalCommands().registerCommand(
        new TerminalCommand.Builder()
            .withName("whereiam")
            .withDescription("显示当前世界与坐标。")
            .withUsage("/whereiam")
            .withProvider(this)
            .build((r, b) -> {
                var pos = b.getPosition();
                getLogger().info("pos=({}, {}, {})", pos.getX(), pos.getY(), pos.getZ());
            })
    );
}
```

## API 速查

| 方法 | 用途 |
|------|------|
| `.withName(String)` | 命令触发词（不带前缀） |
| `.withDescription(String)` | 帮助输出中显示 |
| `.withUsage(String)` | 参数缺失时显示 |
| `.withProvider(this)` | 标记命令归属哪个插件 |
| `.build(ICommandExecutor)` | Lambda 签名：`(CommandResponse, RobotPlayer) -> void` |

每个插件有**独立的命令命名空间**——不同插件的命令不会冲突。

> [!TIP] Actions-Core 的 Executor 模式
> Actions-Core 把 Lambda 体封装成独立的 `*Executor` 类（构造器接收 `ModuleContext`），让命令保持单薄且可测试。详见 [Actions-Core 命令](../docs_CN/14-Actions-Core-命令.md)。

## 什么时候用哪套？

| 需求 | 用 |
|------|---|
| 玩家在游戏里触发 Bot 行为 | `getCommands()` + `!cmd` |
| 控制台操作者触发 Bot 行为 | `getTerminalCommands()` + `/cmd` |
| 两套都要 | 两个都注册——完全独立 |

## `CommandResponse` 辅助方法

```java
String[] args = response.getCommandList();  // 至少包含一个元素（命令名本身）
String sender = response.getSender();       // 玩家名，或 "terminal"
```

前缀（`!` / `！` / `/`）会被自动剥除，按空白符切分。玩家输入 `/goto 10 20 30` 时，Executor 收到 `["goto", "10", "20", "30"]`。
