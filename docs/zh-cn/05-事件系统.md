# 5. 事件系统

DolphinBot 提供 Bukkit 风格的事件系统：用 `@EventHandler` 注解方法、注册监听器，框架按优先级分发匹配的事件。

## `@EventHandler` 注解

```java
@EventHandler(EventPriority.HIGHEST)
public void onPlayerMove(PlayerMoveEvent event) {
    // 在最高优先级处理 PlayerMoveEvent
}

@EventHandler  // 默认 = EventPriority.NORMAL
public void onChat(PlayerChatEvent event) { ... }
```

## 六个优先级

| 优先级 | 相对位置 |
|--------|---------|
| `LOWEST`  | 最先看到事件 |
| `LOW`     | |
| `NORMAL`  | 默认 |
| `HIGH`    | |
| `HIGHEST` | 倒数第二 |
| `MONITOR` | 最后——仅用于监控 |

## 实现 `IListener`

方案一——独立监听器类（多个处理器时更清晰）：

```java
import org.angellock.impl.events.IListener;
import org.angellock.impl.events.annotations.EventHandler;
import org.angellock.impl.api.events.game.PlayerMoveEvent;

public class MyListener implements IListener {
    @EventHandler(EventPriority.HIGHEST)
    public void onPlayerMove(PlayerMoveEvent event) {
        var player = event.getPlayer();
        System.out.println(player.getName() + " 移动了！");
    }

    @EventHandler(EventPriority.LOW)
    public void onChat(PlayerChatEvent event) {
        System.out.println("聊天: " + event.getMessage());
    }
}
```

方案二——插件类自身（临时处理器更方便）：

```java
public class MyPlugin extends AbstractPlugin implements IListener {
    @Override
    public void onEnable(RobotPlayer bot) {
        getEvents().registerListeners(this); // 自身即为监听器
    }

    @EventHandler
    public void onEntitySpawn(EntityEmergedEvent event) {
        System.out.println("实体出现: " + event.getEntity());
    }
}
```

## 注册

```java
@Override
public void onEnable(RobotPlayer bot) {
    getEvents().registerListeners(new MyListener());
    // 或
    getEvents().registerListeners(this);
}
```

## 内置事件

| 事件 | 触发时机 |
|------|---------|
| `PlayerMoveEvent` | 附近玩家移动时 |
| `EntityEmergedEvent` | 实体生成（玩家、抛射物等） |
| `PlayerChatEvent` | 玩家发送游戏内消息 |
| `MessageBroadcastEvent` | 其他 Bot 发送跨 Bot 消息 |

> [!NOTE] 规则
> - 每个处理器方法 **必须** 是 `public`
> - 每个处理器方法都要 `@EventHandler` 注解
> - 一定要注册监听器——未注册的会被静默忽略

## 事件 vs 包监听器

两者都能用，但层级不同：

| 层级 | 你看到的是 | 适用场景 |
|------|-----------|---------|
| `@EventHandler` 事件 | 语义化对象（`PlayerMoveEvent`、`EntityEmergedEvent`） | 关心**发生了什么** |
| 包监听器 | 原始 MCProtocolLib 包（`ClientboundEntityPositionSyncPacket`…） | 关心**线格式** |

对大多数插件来说优先用 `@EventHandler`。只有当事件包装器没暴露需要的字段时才退到包监听器。
