# 2. 快速上手

从零构建一个最小可用插件。复制、修改、打包、扔进 plugins 目录——下次 Bot 启动时就能看到 "Hello, DolphinBot!"。

## Maven `pom.xml` 模板

```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0
                             http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <groupId>org.me</groupId>
    <artifactId>my-plugin</artifactId>
    <version>1.0.0</version>
    <packaging>jar</packaging>

    <properties>
        <maven.compiler.source>17</maven.compiler.source>
        <maven.compiler.target>17</maven.compiler.target>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
    </properties>

    <dependencies>
        <!-- system scope：依赖预构建的 DolphinBot shaded JAR -->
        <dependency>
            <groupId>io.github.neonangelthreads</groupId>
            <artifactId>dolphinbot</artifactId>
            <version>1.6.0-ALPHA</version>
            <scope>system</scope>
            <systemPath>${project.basedir}/../target/DolphinBot-1.6.0-ALPHA-full-shaded.jar</systemPath>
        </dependency>
    </dependencies>

    <build>
        <resources>
            <resource>
                <directory>src/main/resources</directory>
                <filtering>false</filtering>
            </resource>
        </resources>
        <plugins>
            <plugin>
                <artifactId>maven-compiler-plugin</artifactId>
                <version>3.13.0</version>
            </plugin>
            <plugin>
                <artifactId>maven-shade-plugin</artifactId>
                <version>3.6.0</version>
                <executions>
                    <execution>
                        <phase>package</phase>
                        <goals><goal>shade</goal></goals>
                        <configuration>
                            <createDependencyReducedPom>false</createDependencyReducedPom>
                            <artifactSet>
                                <excludes>
                                    <!-- 严禁打包框架已有的内容 -->
                                    <exclude>io.github.neonangelthreads:dolphinbot</exclude>
                                </excludes>
                            </artifactSet>
                        </configuration>
                    </execution>
                </executions>
            </plugin>
        </plugins>
    </build>
</project>
```

## 入口类

```java
package org.me.plugin;

import org.angellock.impl.RobotPlayer;
import org.angellock.impl.plugin.AbstractPlugin;

public class MyPlugin extends AbstractPlugin {
    @Override public String getPluginName()    { return "MyPlugin"; }
    @Override public String getVersion()       { return "1.0.0"; }
    @Override public String getDescription()   { return "Hello DolphinBot"; }

    @Override
    public void onLoad() {
        // JAR 首次扫描时调用一次。此时没有 Bot。
        getLogger().info("加载中 " + getPluginName());
    }

    @Override
    public void onEnable(RobotPlayer bot) {
        // 每个 Bot Profile 加入服务器时调用一次。
        getLogger().info("你好，" + bot.getProfileName() + "！");
    }

    @Override
    public void onDisable() {
        // Bot 断开连接或关闭时调用。
        getLogger().info("再见，世界。");
    }
}
```

## `plugin.json`

在 `src/main/resources/plugin.json` 创建：

```json
{
  "entry": "org.me.plugin.MyPlugin",
  "name": "MyPlugin",
  "version": "1.0.0"
}
```

## 构建 + 部署

```powershell
# 构建（DolphinBot 根目录有 wrapper）
$MVN = "C:\Users\<你>\.m2\wrapper\dists\apache-maven-3.9.16-bin\<hash>\apache-maven-3.9.16\bin\mvn.cmd"
& $MVN -f "my-plugin/pom.xml" package -DskipTests

# 部署
Copy-Item my-plugin\target\my-plugin.jar DolphinBot\target\plugins\my-plugin.jar
```

## 快速验证

启动 Bot，日志应出现：

```
[INFO] Loading MyPlugin - 1.0.0
[INFO] Hello, <ProfileName>!
```
