# 1. 插件结构

每个 DolphinBot 插件都是一个**shaded JAR**（依赖打包进 jar），jar 根目录必须包含清单文件。框架启动时会扫描 `plugins/` 目录下的所有 JAR，读取清单并加载入口类。

## 清单文件 — `plugin.json`

```json
{
  "entry": "org.me.plugin.MyPlugin",
  "name": "MyPlugin",
  "version": "1.0.0"
}
```

| 字段 | 必填 | 说明 |
|------|:----:|------|
| `entry`  | ✅ | 入口类的全限定名（必须继承 `AbstractPlugin`） |
| `name`   | ✅ | 日志中显示的插件名 |
| `version` | ✅ | 自由格式字符串 |

> [!TIP] 入口类回退机制
> 如果 `plugin.json` 缺失，框架会扫描 JAR 中所有继承了 `AbstractPlugin` 的类。若匹配到多个则全部跳过并输出警告。

## 磁盘布局

```text
DolphinBot/
├── target/
│   ├── DolphinBot-1.6.0-ALPHA-full-shaded.jar
│   └── plugins/
│       ├── my-plugin.jar                ← 对所有 Bot Profile 生效
│       ├── Actions-Core-1.0.0.jar       ← 另一个全局插件
│       └── <ProfileName>/               ← 仅对特定 Bot Profile 生效
│           └── per-bot-plugin.jar
└── ...
```

> [!WARNING] 文件锁
> 插件在 Bot 启动时被加载。Bot 运行期间替换插件 JAR 可能导致 JVM 锁文件。替换前请先停止 Bot。

## 为什么必须 shaded JAR？

DolphinBot 使用**共享类加载器**加载插件——MCProtocolLib 和框架类已经在 App 类路径上。你的插件必须：

1. 只打包自己的代码 + 框架**没有**的第三方依赖
2. **严禁**打包 MCProtocolLib、ViaProxy、Geyser 或 DolphinBot 本身——这些已经在框架类路径上

> [!IMPORTANT]
> 实践中这意味着你**必须**使用 Maven Shade Plugin 并把 `DolphinBot-*-full-shaded.jar` 声明为 `<scope>provided</scope>`。见 [快速上手 § Maven POM 模板](./02-快速上手.md#maven-pomxml-模板)。

## 最小可用 JAR

```text
my-plugin.jar
├── plugin.json                    ← JAR 根目录清单
└── org/
    └── me/
        └── plugin/
            └── MyPlugin.class     ← 编译后的入口类
```

不要嵌入嵌套 JAR 或 fat-classpath 工具——只放你的类文件 + `plugin.json`。
